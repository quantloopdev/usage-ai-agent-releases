# Usage AI agent releases

This public repository contains the official standalone device-agent binaries
published by QuantLoop. Product source code, telemetry, credentials, enrollment
tokens, and user data are not stored here.

Install a device from the authenticated Usage AI onboarding screen. It provides
a short-lived, platform-specific command and verifies the selected binary
against the release manifest's exact byte size and SHA-256 digest.

Do not copy enrollment commands into issues or support messages: their tokens
are temporary credentials.
